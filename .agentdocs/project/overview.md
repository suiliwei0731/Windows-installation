# 项目概况：Windows 11 纯净装机环境

## 一、目标

搭建一套可重复使用的 Windows 装机资源库与自动化脚本，用于系统重装后的驱动安装、运行库部署、基础软件安装及环境初始化。

- 安装包集中存放于独立装机硬盘，不依赖系统盘。
- 优先使用微软、硬件厂商、软件项目的官方安装包。
- 优先保证网卡驱动可用，确保重装后能够联网。
- 支持手动安装，也支持通过脚本按顺序执行。

## 二、分层架构

| 层 | 职责 | 落地形式 |
| --- | --- | --- |
| 资源层 | 存放 ISO、驱动、运行库与软件安装包 | `00_System` ~ `05_Applications` 目录 |
| 配置层 | 记录名称、版本、架构、下载地址、安装参数及校验值 | `config/*.json` |
| 执行层 | 完成环境检查、安装与更新 | `06_Scripts/*.ps1` |
| 日志层 | 记录安装结果、失败原因与执行时间 | `07_Logs`、`09_Reports` |
| 更新层 | 检查官方新版本，下载至暂存目录，验证后再归档 | `08_DownloadCache` |

## 三、执行流程

检查系统 → 检查网络 → 安装网卡驱动（如需要）→ 更新 Windows → 安装芯片组与硬件驱动 → 安装运行库 → 安装基础工具 → 生成安装报告。

## 四、范围边界

- 第一阶段（MVP）只准备资源：识别装机硬盘、建立目录、生成软件清单、检查安装包、计算 SHA-256、记录日志。
- 第一阶段不得执行任何真实系统修改（不装驱动、不改注册表、不重启、不格式化）。
- 后续阶段再逐步增加驱动安装、运行库安装与环境初始化功能。
- 安装类脚本必须支持模拟执行（DryRun），并先提供模拟结果供用户确认。

## 五、安全原则

1. 所有下载优先使用官方 HTTPS 来源。
2. 不关闭 Windows Defender、UAC 或驱动签名验证。
3. 不使用来源不明的万能驱动包、DLL 合集、破解软件或未经验证的系统精简工具。
4. 下载文件必须执行 SHA-256 校验，校验值需与可信来源一致。
5. 静默安装参数必须以官方文档为依据，不得由脚本猜测。
6. 安装脚本应可重复执行，失败时保留日志并停止依赖该步骤的后续操作。
7. 对有风险的系统修改必须要求用户确认，不得默认自动执行。
8. 敏感配置不得保存密码、激活密钥或其他凭据。
