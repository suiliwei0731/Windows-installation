# ADR-001：资源根目录不写死盘符，按标记文件自动识别

## 背景

`readme.md` 目录规划以 `D:\InstallKit` 为例，但装机硬盘盘符在不同机器、不同重装环境下可能变化（可能为 `D:`、`E:` 或用户自定义子目录）。若脚本写死盘符，换机或换线缆后即失效。

## 方案

1. 方案 A：写死盘符 `D:`。简单，但不可移植。
2. 方案 B：使用脚本所在目录的相对路径回溯。可移植，但脚本被复制到别处后失效。
3. 方案 C（选定）：以 `config\settings.json` 为根目录标记文件，按「显式参数 → settings.json 记录的 library_root → 脚本目录向上回溯」的顺序定位根目录。

## 决定

采用方案 C。任何脚本都通过统一的定位逻辑获取根目录，忽略其自身所在盘符。

## 原因

- 满足 readme「脚本不得假设硬盘始终是 D:」的硬性要求。
- 标记文件方案语义明确，且天然支持在同一硬盘上并存多个资源库。
- 顺序回退策略兼顾显式指定与自动定位，容错性更高。

## 禁止

- 禁止在脚本中硬编码盘符（如 `D:\InstallKit`）。
- 禁止在定位失败时静默使用某个默认路径继续执行；必须报错并要求用户指定。
